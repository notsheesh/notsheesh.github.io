# notsheesh.github.io

Plain HTML. No build.

- `index.html`: the main page
- `about.html`: the longer about me
- `commonplace.html`: notes, one `<p data-date="...">` each (date not shown)
- `thought-stream.html`: thought stream
- `style.css`, `popup.js`: shared style and hover popups (`data-tip="..."`)

Open `index.html` in a browser to preview. Pushing to `main` deploys to GitHub Pages.
